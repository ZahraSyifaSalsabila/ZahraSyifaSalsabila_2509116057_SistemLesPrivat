## Deskripsi Singkat Program

Sistem Pengelolaan Data Les Privat adalah program berbasis Java yang digunakan untuk membantu mengelola data yang berkaitan dengan kegiatan les privat. Sistem ini digunakan untuk mencatat data siswa, data tutor, dan jadwal les. Pengguna dapat menambahkan data baru, melihat data yang sudah tersimpan, mengubah data, dan menghapus data sesuai kebutuhan.

Pada data siswa, informasi yang dikelola meliputi ID, nama, jenjang, dan mata pelajaran. Pada data tutor, informasi yang dikelola meliputi ID, nama, keahlian, dan nomor telepon. Sedangkan pada data jadwal, informasi yang dikelola meliputi ID jadwal, siswa, tutor, hari, dan jam.

Program ini menggunakan menu utama agar pengguna dapat memilih proses yang ingin dilakukan. Data yang sudah dimasukkan akan disimpan selama program berjalan dan dapat dikelola kembali melalui menu yang tersedia.

## Penjelasan Alur Program

Ketika program dijalankan, pengguna akan melihat menu utama yang terdiri dari Tambah Data, Tampilkan Data, Update Data, Hapus Data, dan Keluar. Pengguna dapat memilih menu sesuai kebutuhan.

### 1. Tambah Data

Langkah-langkahnya:
1. Pilih menu id 1 **Tambah Data**.
2. Pilih data yang ingin ditambahkan, yaitu siswa, tutor, atau jadwal.
3. Masukkan informasi yang diminta.
4. Data akan tersimpan dan dapat dilihat melalui menu Tampilkan Data.

### 3. Update Data

Langkah-langkahnya:
1. Pilih menu id 3 **Update Data**.
2. Pilih jenis data yang ingin diubah.
3. Masukkan ID dari data yang ingin diubah.
4. Masukkan informasi baru.
5. Data yang dipilih akan diperbarui.

4. Data yang dipilih akan dihapus.
